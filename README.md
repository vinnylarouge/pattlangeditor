# ML Diagram Editor (Rewrite)

A clean, modern diagram editor for Machine Learning architectures, inspired by Chyp and Picotron.

## Features
- **Simplified Node Types**: Learnable, Function, Copy, Delete.
- **Drag-and-Drop Interface**: Intuitive palette and canvas interaction.
- **Custom Wire Types**: Define your own types with colors and symbols.
- **Box Signature Editor**: Customize node inputs and outputs.
- **Export**: Export to PyTorch code.

## Tech Stack
- Python 3.10+
- PySide6 (Qt for Python)
